# NUEVE Studio replica

Réplica local del sitio de referencia, incluyendo sus cuatro rutas, fotografías,
tipografías, transiciones, filtros, modales y comportamiento responsive.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Las fotografías se sirven desde Unsplash con los mismos identificadores y
encuadres usados por la referencia.
